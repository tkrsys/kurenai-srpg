# 顔グラフィック

会話ウィンドウとユニット情報パネルに表示される顔グラフィックです。
`<name>.png` があればそれを、無ければ `<name>.svg` を使います。どちらも無いキャラは記号マークのまま表示されます。

現在の SVG はドット絵風の仮ポートレートで、`tools/make_portraits.py` が生成しています（ドットマップと色を編集して再実行すると更新されます）。
本番のイラストに差し替えるときは、同じファイル名の PNG（正方形、256×256 以上推奨）を置くだけで優先されます。

| ファイル名 | キャラ |
|---|---|
| `ars` | アルス（ロード） |
| `gald` | ガルド（ソシアルナイト） |
| `lina` | リーナ（アーチャー） |
| `bern` | ベルン（ファイター） |
| `celia` | セリア（マージ） |
| `mira` | ミラ（シスター） |
| `volg` | ヴォルグ（ボス・ジェネラル） |
| `soldier` | 敵・兵士（共通） |
| `fighter` | 敵・戦士（共通） |
| `knight` | 敵・騎士（共通） |
| `archer` | 敵・弓兵（共通） |
| `mage` | 敵・魔道士（共通） |
