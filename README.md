# 紅の継承者 ― 第1章 城門奪還

ヴェスタリアサーガ風のマス目型シミュレーションRPGのブラウザ版プロトタイプです。
HTML + Canvas + JavaScript の単一ファイル（`index.html`）で動作し、外部依存はありません。

## 遊び方

- 自軍ユニットをクリック → 青いマスへ移動
- 移動後にメニューから「攻撃」「杖」「待機」を選択
- 赤いマスは攻撃可能範囲。Esc または別のマスをクリックで取り消し
- 勝利条件：アルスが城門に到達して「制圧」（または敵の全滅）
- 敗北条件：アルスの死亡。倒れた仲間は戻りません

## 実装済みの要素

- 地形効果（森・山・砦・城門の回避/守備ボーナス、砦・城門での回復）
- 移動範囲・攻撃範囲の表示、戦闘予測（ダメージ・命中・必殺・追撃）
- 攻撃 → 反撃 → 追撃（速さ差4以上）。武器の三すくみは無し
- 経験値・レベルアップ（成長率による乱数成長）、戦死は復活なし
- 敵AI：積極型／守備型（攻撃されると動き出す）／ボス（動かない）
- オープニング会話、ボス戦前の会話、勝利・敗北画面

## ローカルで動かす

```bash
node serve.js
```

ブラウザで http://127.0.0.1:8765 を開きます。
